ここに「次に投稿したい商品」を置きます。置いたものは、自動で選ばれる商品より優先して投稿されます（古い順に1日1件）。

■ 置き方
1. この inbox フォルダの中に、投稿ごとにフォルダを作る（名前は自由。例: イヤホン）
2. そのフォルダに memo.txt を入れる（写真は任意）

■ memo.txt の書き方で、投稿の種類が変わります

【A】持っている商品を、自分の写真で紹介（いちばん売れやすい）
  memo.txt … 楽天の商品URLを1つ + 自分の感想
  写真     … 1.jpg, 2.jpg …（最大8枚。1枚目が表紙）

  例)
  https://item.rakuten.co.jp/shopname/itemid/
  ジャンル: gadget
  通勤で毎日使ってる。電車の音がほぼ消える。ケースが小さい。

【B】持っていない商品を1つ紹介
  memo.txt … 楽天の商品URLを1つだけ（写真は入れない）
  → 文字のカード1枚で、価格・レビューなどの事実だけで紹介します

【C】持っていない商品をまとめて紹介（まとめ・比較投稿）
  memo.txt … 楽天の商品URLを2〜8個 + テーマ（任意）
  → 表紙・商品ごとのスライド・比較表の複数枚投稿になります

  例)
  テーマ: 機内持ち込みできる旅行グッズ
  ジャンル: travel
  https://item.rakuten.co.jp/shopA/item1/
  https://item.rakuten.co.jp/shopB/item2/
  https://item.rakuten.co.jp/shopC/item3/

■ ジャンルの書き方（任意）
  gadget / travel / training / appliance / book / investment

■ 注意
- 写真のファイル（このリポジトリは公開されます）にはスマホの位置情報が入っていることがあります。
  カメラ設定で位置情報をオフにしてから撮影してください。
- 使い終わったフォルダは自動で削除され、memo.txt の控えだけが inbox/_used/ に残ります。
- 何も置いていない日も止まりません。水・土は自動でまとめ投稿、それ以外の日は人気商品の単品紹介になります。
